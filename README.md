# SkinWise

SkinWise is a beginner-friendly skincare recommendation website built as a static HTML/CSS/JavaScript project. It helps users find suitable skincare products based on skin type, concerns, environment, lifestyle, and budget.

## Files

- `index.html` - landing page and quiz interface
- `styles.css` - responsive styling and brand visuals
- `script.js` - interactive quiz logic and product recommendations

## How to use

Open `index.html` in a browser to start the SkinWise quiz.
